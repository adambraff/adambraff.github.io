# MABEL

Machine-Assisted Bayesian Evidence Lab: a read-only snapshot of Adam Braff's forecasting pipeline for the Narcissist Forecasting Contest.

The page shows each prop's rules, research plan and final call, the market price that was unsealed after the call, and a track record of every forecast the pipeline has made. The working copy, where gates are answered, is a private page; this one is rebuilt from it by hand and does not update on its own.

Unlisted on purpose: there is no tile for it on the homepage, and the page asks search engines not to index it.

Single self-contained `index.html` with the data embedded, plus `mabel.png`. No backend.

## Versions

The pipeline is versioned (currently MABEL 2.0.0). Every forecast on the Track record tab carries the version that produced it, and the How it works tab shows the current schematic and the change log. The same log is in [VERSIONS.md](VERSIONS.md).
