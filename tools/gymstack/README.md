# 2026 gym tech stack

Interactive map of how member and employee actions move data through the layers of a gym's technology stack: core platform, revenue engine, member experience, operations, and data and decisions, plus third-party data.

Pick a scenario (joins online, requests a trial, checks in, books a class, complains, stops visiting, tries to cancel, misses a payment, hires a trainer, works a shift, leaves the job) and step through each hop: what moves, how and when it moves, who acts, which system owns each fact, and how the outcome is measured.

Single self-contained `index.html`, no build step. All names, scores and dollar figures are synthetic.

Live at https://adambraff.github.io/tools/gymstack/
