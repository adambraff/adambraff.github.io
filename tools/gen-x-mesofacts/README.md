# Gen X Mesofacts

Interactive charts of the large, slow American trends of a Gen X lifetime (roughly 1970 to today): teen births, crime, smoking, college, oil, newspapers, and more. A toggle overlays the 1985–90 trend extended to 2025, showing what the future looked like from 1990.

- Single self-contained `index.html` (Chart.js from cdnjs, Archivo from Google Fonts)
- Data compiled from CDC NCHS, FBI UCR, NHTSA, BLS/FRED, EIA, OMB, NCES, Census, Gallup, College Board, USPS, USDA ERS, MIT Election Lab and others; each chart cites its source and notes gaps and definition breaks.

Live: https://adambraff.github.io/tools/gen-x-mesofacts/
