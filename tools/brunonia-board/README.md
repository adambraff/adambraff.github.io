# First Bank of Brunonia: live board

A projector-friendly scoreboard for the Brunonia classroom simulation. It polls the results feed every few seconds and shows each team's latest submitted plan: use case, data sources, technique, added controls, release strategy, a delivery timeline bar, and the team's probability forecast.

- Add `?demo` to the URL to preview with sample teams.
- Press `S` (or hover bottom-left) to switch ordering between submission time and target full rollout.

All banks, people, and data in the exercise are fictional.
