AEO/GEO Visibility Tracker

1. Answer engines

Enter API keys for the engines you want to poll. Keys are stored only in this browser's localStorage and sent directly to each provider. Recommended starting point: Gemini (cheapest, web-grounded, returns citations, works cleanly from the browser). Gemini also powers the AI scoring/"judge" step.

CORS note: Gemini, OpenAI, and Anthropic respond to direct browser calls (Anthropic needs the dangerous-direct-browser-access header, which the tool sets). Perplexity often blocks browser calls; if it errors, leave it off or run it through a proxy. Models drift — the model name fields are editable so you can bump them without touching code.
No key? Claude runs need no key at all: ask Claude (in Cowork) to "run the CB AEO/GEO battery" — it runs every query through live web search, scores with the same rubric, and commits the run to data/cbgeo-history.json in the repo, which this page auto-loads. A weekly scheduled Claude run keeps the trend fed.

3. Run the diagnostic

Each enabled query is sent to each enabled engine, then an AI "judge" scores presence, prominence, recommendation, sentiment, and citations. Cost is roughly (#queries × #engines × ~$0.002) per run with Gemini Flash. A full battery runs in a couple of minutes.

Claude runs (no API key)

A parallel engine series, run by Claude in Cowork via live web search using the same battery and rubric, saved with engine: "claude". To trigger one manually, tell Claude: "Run the AEO/GEO battery for this client and commit the results." A weekly scheduled task does this automatically. Claude runs and Gemini runs are kept as separate series — compare them in Trend & data → Engine comparison rather than mixing them.

Visibility scorecard

All runs in the selected window are pooled. Defaults to the last 7 days. Drag the sliders to move or narrow the window (set both to the same run for a single-run view).

Share of Voice = % of queries where that query's tracked brand (Viking, Lynx, AGA, Rangemaster, or La Cornue) is mentioned — pooled across the five. "Composition Brands" is the portfolio owner and is never itself measured; the By-brand table below is the per-brand view. Prominence (0–3) = how featured the brand is when mentioned (3 = led/recommended, 1 = afterthought). Owned-citation share = % of cited sources on an owned domain. Deltas compare against the preceding window of the same size.
