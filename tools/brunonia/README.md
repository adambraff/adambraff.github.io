# First Bank of Brunonia

A phone-first classroom simulation of an analytics investment decision. Teams pick a use case, up to three data sources, an analytic technique, any number of controls, and a release strategy, then forecast the probability that the project will succeed. A running delivery timeline shows how each choice moves the production and full-impact dates.

Single self-contained `index.html` (no build step, no backend). Progress is saved in the browser; the final screen can be shared as text or screenshotted.

All banks, people, and data in the exercise are fictional.
